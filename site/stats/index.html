How this is counted

Every copy of Duck looks for an update once a day. The site counts each one as a Mac, using a code made from its network address that changes every day and cannot be turned back into the address. Nothing in Duck itself sends anything new.

Macs sharing one network count as one. A Mac with automatic updates turned off is not counted. Weekly and monthly figures are daily averages, because the code changes each day and the same Mac cannot be followed across days.

Site downloads are the download button. Terminal, Homebrew and Duck's own updates all use one file, so they are counted together.
